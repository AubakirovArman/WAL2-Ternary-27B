# Исследовательские предложения

Используйте GitHub Issues после публикации репозитория. Опишите проверяемую гипотезу и ограниченный опыт от одного фиксированного checkpoint. Указывайте source revision, dataset/task hashes, seed, протокол генерации, бюджет токенов и полные знаменатели. CE и генерационная точность должны сообщаться отдельно; результаты разных моделей/подвыборок нельзя объединять.

Нужна помощь с scale/rotation QAT, корректным длинным reasoning, on-policy дистилляцией, проверкой доказательств и скоростью полного optimizer update. При изменении кода проверяйте затронутую математику и сохранение/экспорт, затем измеряйте качество на согласованном development наборе. Окончательный выбор требует нового независимого test.

Подробные открытые задачи: docs/COLLABORATION_RU.md. Данные, teacher caches, скрытые FP32-веса и сгенерированные большие файлы не добавляйте в обычный Git commit; их состав и лицензии должны быть указаны отдельно. Contributions сохраняют атрибуцию базовой модели и используемых upstream библиотек.
