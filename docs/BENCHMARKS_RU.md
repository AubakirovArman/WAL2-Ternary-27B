## Как самостоятельно проверить опубликованные цифры

```bash
python3 scripts/verify_evidence.py
```

Инструмент пересчитывает корректность/обрезания по каждому ID, сравнивает aggregate JSON, проверяет равенство наборов ID и арифметику битности. Он не выполняет заново ответы модели и не проверяет самостоятельно gold разметку. Полный повтор генерации требует model weights, совместимого runtime, задач с правильными лицензиями и того же протокола.
